# 個人交易策略（魚尾選股 + 分批進出 + 賣弱買強）

> 記錄日期：2026-06-17
> 用途：沉澱 Brian 對「魚尾系統選出的個股」採用的資金配置與進出場紀律，並作為回測機制化依據。
> 結構：**Part A 原始策略（人話版）** → **名詞定義表** → **Part B 回測機制化規則** → **回測結果** → **限制** → **重現方式**。

---

## Part A — 原始策略（決策權在使用者）

### 1. 資金配置
- 總資金假設 **100 萬**，切成 **10 份**，每份 **10 萬**，最多同時持有 10 檔。
- 魚尾訊號進來，挑喜歡的標的買，一次先買 **0.5 份（5 萬）**。

### 2. 初始進場
- 初始買進固定 **0.5 份**。

### 3. 進場後三情境
| 情境 | 條件 | 動作 |
|------|------|------|
| a. 走強 | 漲 **+9% ~ +10%** | 考慮加碼 **0.25 ~ 0.3 份** |
| b. 走弱 | 跌 **-8% ~ -12%** | 進入**觀察**（不立即砍） |
| c. 盤整 | **10 ~ 15 天**沒轉強 | **減碼一半或全賣** |

### 4. 虧損股票處理（跌到 -8% ~ -12% 後依序檢查）
1. 原本買進理由還在嗎？不在 → 直接賣。
2. 大盤有沒有轉弱？有 → 減碼一半或全賣。
3. 同族群是不是還強？轉弱 → 減碼一半或全賣。
4. 2 ~ 3 天內有沒有站回關鍵價？
   - 有站回且**籌碼沒壞** → 補 **0.25 份**。
   - 沒站回 → 減碼一半或全賣。

### 5. 賣弱買強（資金輪動）
弱股 A（虧損／沒站回／籌碼轉弱／族群轉弱／沒資金效率）vs 強股 B（有浮盈／回測守住／籌碼續強／族群仍強／有明確加碼點）。
符合多點 → 賣掉 A 的 0.5 份轉到 B，但 **B 不一次打滿，最多加 0.25 ~ 0.3 份**。

## 名詞定義表（回測程式用的變數，先看懂這張表再看規則）

| 名詞 | 定義 |
|------|------|
| **1 份** | 10 萬元。初始 0.5 份＝5 萬；走強加碼 0.3 份＝3 萬；虧損補倉 0.25 份＝2.5 萬。 |
| **進場日 `entry_date`** | 魚尾追蹤的第 2 個交易日（`baseline_trade_date`）。 |
| **進場價 `entry_price`** | 該日 `(開盤+收盤)/2`（＝魚尾 `baseline_price`，與追蹤口徑一致）。 |
| **平均成本 `avg_cost`** | 累計投入金額 ÷ 累計股數；每次加碼／補倉後重算。 |
| **`r_entry`** | `收盤 / entry_price − 1`。相對「最初進場價」的報酬，用來判斷「有沒有真的轉強／站回」。 |
| **`r_avg`** | `收盤 / avg_cost − 1`。相對「目前平均成本」的報酬，用來判斷加碼（+9%）與停損（-10%）。 |
| **`ma5` / `ma10`** | 個股收盤 5 日 / 10 日均線。 |
| **關鍵價** | ＝個股 5 日線（`ma5`）。 |
| **狀態 `normal`** | 正常持有。 |
| **狀態 `observe`** | 跌到 `r_avg ≤ -10%` 後進入的觀察狀態。 |
| **狀態 `exited`** | 已出場。 |
| **大盤廣度指數** | DB 無加權／櫃買指數表，改用「全市場個股當日報酬等權平均」累積成的代理指數。 |
| **大盤轉弱** | 廣度指數**跌破自身 10 日線**，**或**近 3 個交易日跌幅 > 5%（兩者取 OR）。 |
| **族群** | 個股的 `sub_industry`。 |
| **族群轉弱** | 該 `sub_industry` 成分股的「外資+投信淨額加總」連續 2 日為負；若該族群無法人資料，改看成分股日報酬中位數連續 2 日為負。 |
| **籌碼壞掉** | 外資+投信合計連續 3 日淨賣超，**或**該股當日淨賣超落在全市場最賣超前 50 名。 |
| **強勢候選** | 當日持股或候選池中存在任一檔 `r_entry ≥ +12%`。 |
| **`weak_score` / `strength_score`** | 賣弱買強用的弱股／強股計分（見 Part B §15）。 |

## Part B — 回測機制化規則

所有觸發都以**收盤價**判斷、收盤價成交（不假設盤中觸價）。三個版本：

- **v1**：每檔獨立、簡化觀察（觀察 3 日內收盤站回「進場價」就補 0.25 份，否則停損）。
- **v1_5**：每檔獨立、真實觀察（觀察 2 日，逐日檢查大盤／族群／籌碼，站回＝收盤站上 5 日線且 `r_entry > -8%`）。
- **v2**：在 100 萬資金池內跑、最多持有 10 檔、含**賣弱買強**跨股輪動。

### 標的與時間
- 標的池：魚尾「永久紀錄區」`signal_watch_completed_archives`。
- 每檔進場日＝`baseline_trade_date`，進場價＝`baseline_price`，追蹤至 `completed_trade_date`（最多 30 個交易日）。
- v2 為**組合層級**：依交易日由早到晚逐日模擬，每日收盤後依 §22 順序執行。

### 走強加碼
`normal` 狀態下 `r_avg ≥ +9%` 且尚未加碼 → 加 0.3 份（不超過單檔上限 1 份、不超過現金），重算平均成本。

### 虧損觀察
`normal` 狀態下 `r_avg ≤ -10%` → 進入 `observe`。
`observe` 期間（最多 2 日，v1 為 3 日）逐日檢查：
1. 大盤轉弱 → 全部出場。
2. 族群轉弱 → 全部出場。
3. 籌碼壞掉 → 全部出場。
4. 站回關鍵價（收盤 ≥ `ma5` 且 `r_entry > -8%`）且籌碼未壞 → 補 0.25 份，回 `normal`。
5. 滿 2 日仍未站回 → 停損全部出場。
- **補倉限制**：每檔最多補一次；若已補過又再跌到 `r_avg ≤ -10%`，不再觀察，直接全部出場。

### 盤整出場
`normal` 且持有 ≥ 13 天、從未走強加碼、`r_entry < +5%` → 視為沒轉強；**v2 須當日存在「強勢候選」**才把盤整股賣出（規則 c 的全賣）。

### 賣弱買強（僅 v2）— §15
- **弱股 A**：A1 `r_avg<0`、A2 收盤 < `ma5`、A3 籌碼壞、A4 族群轉弱、A5 持有 ≥ 13 天且 `r_entry<+5%`。
  進入弱股清單需 `weak_score ≥ 2` 且至少含 A1 或 A5（必須真的虧或真的沒效率）。
- **強股 B**：B1 `r_entry>0`、B2 `r_entry≥+12%`、B3 收盤 ≥ `ma5`、B4 籌碼未壞、B5 族群未轉弱、B6 未達單檔上限。
  進入強股清單需 `strength_score ≥ 3` 且**必含 B2、B6**。
- **輪動觸發**：同日同時有 A、B，且 `B_r_entry − A_r_entry ≥ 10%`。
  賣掉 A 全部；B 已持有→加 0.3 份，B 未持有→新進 0.5 份。每日最多輪動 2 次。
- **§21 鐵則**：一檔股票**賣出後，剩餘期間不再買回**；每檔最多「初始進場 1 次＋走強加碼 1 次＋虧損補倉 1 次＋輪動加碼 1 次」。

### 每日執行順序（§22）
1 更新 `r_avg/r_entry/ma5/籌碼/族群/大盤` → 2 observe 風險檢查 → 3 observe 站回補倉 → 4 normal 是否 -10% 進 observe → 5 normal 走強加碼 → 6 盤整出場 → 7 建弱股 A 清單 → 8 建強股 B 清單 → 9 賣弱買強（≤2 次）→ 10 當日新進場 → 11 期末出場、更新現金與市值。

### 大盤代理（重要說明）
DB **沒有**加權／櫃買指數的歷史日線表，所以「大盤」用**全市場個股等權報酬累積的廣度指數**代理；不分上市／上櫃，只用單一大盤。轉弱定義＝跌破 10 日線 **OR** 近 3 日跌幅 > 5%。

## 回測結果（2026-06-17 執行）

- 標的：永久紀錄區 **68 檔**（first_seen 2026-04-28 ~ 05-07，completed 06-09 ~ 06-16）。
- 方法：round-robin 平均分成 **7 組**（每組約 10 檔），每組各自當一個 100 萬資金池跑。
- 期間：約 **34 個交易日（約 7 週）**。

| 指標 | v1 純分批進出 | v2 加賣弱買強 |
|------|--------------|--------------|
| 7 組平均報酬（/100萬） | **+6.15%** | **+5.85%** |
| 投入資金報酬率 | +9.02% | +7.94% |
| 最佳組 / 最差組（/100萬） | +15.33% / +1.40% | +10.23% / +1.77% |

### 結論
1. **這段期間「賣弱買強」小輸純分批抱單**（+5.85% vs +6.15%）。
2. 輪動**壓低波動**（最差組變好、最佳組變差）——砍掉尾部風險，也砍掉大贏家。
3. 主因：規則在**進場第 2 天的淺回檔**就把部位輪掉，加上 §21 賣掉不可買回，導致南亞科（抱到底 +44%）、事欣科（+46%）這類「先回檔後噴出」的標的直接報銷。
4. 這段是**強多頭窗口**（這批魚尾股 Buy&Hold 普遍 +40~50%）；多頭裡早停損 + 輪動天生吃虧，**震盪／空頭窗口結論可能相反**。

### 可調整方向（待驗證）
- 給輪動加「最短持有天數」門檻（例如進場 5 日內不准被輪掉），避免砍在剛回檔。
- 弱股 A 的 A1（只是 `r_avg<0`）門檻太鬆，可改為「已進 observe 或已停損確認」才列入弱股。
- 取更長／含空頭的窗口重跑，確認輪動在不同行情下的效果。

## 最佳策略建議（資料驗證後，2026-06-17）

### 用到的資料
- 已封存 68 檔（完整 cycle）＋正在追蹤、已追蹤 >20 交易日的 91 檔 active 魚尾。
- 約束：**最多 10 檔、本金 100 萬、不可無限加碼**；目標**至少 +10%**（每檔追蹤天數本就不一致，回測各自從進場跑到自身追蹤期滿）。

### 資料三大發現
1. 魚尾股「抱到追蹤期滿」平均 **+11.3%**、勝率 66%；但**平均最大正報酬 +29%**，期末只剩 +11% → 峰值回吐約 18%。
2. 按類型：**FOLLOWER 最優**（+12.6%、勝率 72%、最大回撤僅 -7%）；LAGGARD 中庸（+11.6%）；**LEADER 最危險**（勝率 50%、平均最大回撤 -25.8%，兩極分化）。
3. **閒置現金是 /100萬 報酬最大殺手**：每檔只放 0.5 份 → 10 檔只用 50 萬 → +11% 的原料落到 /100萬 只剩 ~6%。

### 早出場在多頭裡會吃虧（實測）
| 策略 | 7 組平均 /100萬 |
|------|----------------|
| v2 賣弱買強 | +5.85% |
| best 移動停利（峰值 +15% 後回落 10% 出） | +5.71% |
| v1 純分批（半倉、3 日站回） | +6.15% |
| **推薦：全部署 + 抱到底 + -12% 停損** | **+10.37%** ✅ |

### 推薦策略（達標 ≥10%）
1. **盡量填滿 10 檔、每檔接近 1 份（部署滿 100 萬）**——衝破 10% 的第一槓桿，半倉睡錢只有 6%。
2. **選股偏重 FOLLOWER**，把平均每檔拉到 +13~15%，墊高最差組地板。
3. **LEADER 嚴管**：進場後 5 日內不轉強、或先觸 -12% → 立刻砍（組合最大破口）。
4. **抱住贏家、不要早停利**：+9% 後加碼到滿 1 份，讓它跑到追蹤期滿/趨勢轉折。
5. **只砍真輸家**：硬停損 -12%（躲開眾達 -32%、瀚荃 -20% 那種）。
6. **多頭不做賣弱買強**；只有明確進入震盪盤再啟用輪動換掉沒效率部位。

### 驗證結果
全部署 + 抱到底 + -12% 停損，全 68 檔分 7 組：**平均 +10.37%**、最佳組 +22.82%、最差組 +1.53%、投入報酬率 +10.76%。對照只放半倉的 v1 僅 +6.15%——**唯一差別是把資金部署率從 50% 拉到 100%**。

> 注意：此結論建立在 2026-04~06 的**強多頭窗口**。多頭裡「全部署 + 抱住」天生佔優；若進入震盪／空頭，需把停損收緊、降低部署率、並啟用賣弱買強。

## 限制（刻意未處理）
1. 未計手續費、證交稅（v2 交易筆數多，實務上會再被稅吃一截）、滑價、流動性。
2. 未處理整股／零股（股數允許小數）、除權息還原。
3. 觸發與成交都用收盤價，未模擬盤中觸價。
4. 大盤用廣度指數代理，非真實加權指數。
5. 未處理主觀題材強弱、個人「喜不喜歡」、族群過度集中、空頭整體降槓桿。
