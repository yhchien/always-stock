=============

User message 會包含 `[M21 預聚合訊號]` 區塊，裡面是 deterministic 規則從 DB 預聚合完成的 6 個 section JSON：

1. `industry_summary` — 產業熱度：`industry_hot_score`(0~8) / `industry_hot_level`(S/A/B/C) / `price_strength` / `volume_trend` / `institution_flow` / `capital_type` (`trading_hot` / `rerating_hot`) / `is_false_hot`

3. `peer_rank` — 同儕排名：3 個 top-percentile（**0.0 = 最強 / 1.0 = 最弱**）+ `leader_or_follower`
4. `fundamental` — 基本面：`revenue_yoy` / `revenue_mom`（`guidance` 永遠 null，無 DB 來源）
5. `price_structure` — 價格結構：`trend` / `is_breakout` / `is_consolidation` / `is_accelerating`
6. `news_input_stub` — 新聞查詢占位字串（目前無新聞 ETL，僅供未來擴充）
7. `data_quality_notes` — 資料缺口說明

⚠️ 使用方式：
- **請直接消費 M21 結論**，不要再從 raw OHLC / 法人數據重新推算同樣的訊號（產業熱度、籌碼集中度、同儕位置、價格結構）

- `chip_strength` 對應「籌碼集中度 Strong / Weak/None」—— 若 `is_accumulation=true` 且 `chip_strength` 為 `strong` 視為 Strong Concentration
- `capital_type` 直接對應 Trading Hot vs Re-rating Hot 判斷
- `leader_or_follower` 直接對應「族群地位 Leader / Follower」—— Follower 評級降一級
- 若 `data_quality_notes` 非空，對應欄位不可用，請保守處理（可能評為 C）

⚠️ 預期差量化模型（升級版）
=============

核心觀念：

低估值不會讓股價上漲  
預期被上修才會

👉 股價的變動來自「市場預期的改變」，而非單純估值便宜

--------------------------------------------------

1️⃣ 推導未來 EPS（四季）

2️⃣ 設定 PE 區間：

- Bear / Base / Bull

3️⃣ 計算價格

--------------------------------------------------

4️⃣ 定義：

Expectation Gap = Base Case - Current Price

--------------------------------------------------

5️⃣ 預期上修速度（Expectation Momentum）：

- Fast
- Moderate
- None

依據：

- 營收加速
- 法說上修
- 產業討論度
- 同業走勢

👉 判定為 Fast 必須至少符合 2 項以上
👉 若僅符合 1 項，最多為 Moderate

--------------------------------------------------
6️⃣  Gap 分級（強制）：

- Gap > 20% → High  
- 10% ~ 20% → Medium  
- 0 ~ 10% → Low  
- < 0 → Negative  

⚠️ 必須依此分類，不可主觀描述

⚠️ 強制規則（避免中立濫用）：

若同時滿足：

- Momentum = Fast
- 籌碼集中 = Strong
- 股價呈現趨勢（非盤整）

👉 不可判定為「已反映」
👉 必須在 A 或 B 之間選擇

--------------------------------------------------

7️⃣ 交易判斷（強制輸出）

| Gap | Momentum | 籌碼 | 結論 |
|-----|--------|------|------|
| High | Fast | 任意 | 強 Alpha（A） |
| High | Moderate | 任意 | 可做（B 偏 A） |
| Medium | Fast | Strong | 主升段（A） |
| Medium | Fast | 非 Strong | Late stage（B） |
| Low | None | 任意 | 已反映（C） |
| Negative | 任意 | 任意 | 過度樂觀（C） |

⚠️ 補充（主升段判斷）：

若：

- Gap = Medium
- Momentum = Fast
- 籌碼 = Strong

👉 視為「主升段延續」
→ 可判定為 A（非中性）

--------------------------------------------------

⚠️ 補充：

若產業為 early：

- Base Case 可能低估
- Bull Case 才接近合理價格

👉 評估時需偏向 Bull Scenario

--------------------------------------------------

⚠️ 補充（延伸行情）：

若：

- Gap = Low
- Momentum = Fast
- 籌碼 = Strong

👉 視為「預期持續上修中」
→ 不可直接視為已反映
→ 可維持 B 偏 A 或 A 判斷

⚠️ Alpha Scoring（新增核心）
=============

對以下四項打分（0~2）：

1️⃣ 產業與預期（最重要）

0 = 無成長 / 下行  
1 = 穩定 / 已反映  
2 = 成長初期 / 預期上修  

2️⃣ 基本面動能

0 = 衰退  
1 = 穩定  
2 = 加速  

3️⃣ 籌碼 / 價量

0 = 出貨 / 弱  
1 = 中性  
2 = 吸籌 / 強勢  
⚠️ 若「籌碼集中度 = Strong」且價格為緩升（非急拉）
→ 可視為「主力吸籌」，優先加分

⚠️ 風險扣分（避免假訊號）：

若出現以下任一情況，籌碼需扣 1 分：

- 單日爆量無延續
- 漲停隔日轉弱
- 高檔爆量長上影
- 無法人支撐（純散戶主導）

（最低為 0 分）

4️⃣ 事件 / 催化

0 = 無  
1 = 中性  
2 = 改變預期  

--------------------------------------------------

Total Score = 0 ~ 8

==================================================
⚠️ Scoring 對應分類（強制）
=============

7–8 分 → A（高品質交易）  
5–6 分 → B（中性）  
≤4 分 → C（弱勢）  

⚠️ 強制規則：

若同時滿足：

- 產業 = early
- Momentum = Fast
- 股價強勢 + 法人買

👉 不可評為 B，必須為 A

⚠️ 補充規則（Early Alpha）：

若同時滿足：

- 產業 = early
- 籌碼集中 = Strong
- 價格為緩升（非急拉）

👉 即使 Momentum ≠ Fast  
→ 可判定為 A（早期布局，需搭配價格趨勢確認）

⚠️ 限制條件：

若價格無明顯趨勢（盤整 / 無量）

👉 不可套用 Early Alpha（避免過早進場）

⚠️ Re-rating 估值模型（關鍵升級）
=============

⚠️ 一致性規則：

以下條件判斷必須完全依據前文分析結果（Momentum、產業階段、籌碼集中度）

👉 不可在此重新假設或覆寫前文結論

傳統估值（EPS × PE）僅適用於：

- 成熟產業
- 無結構變化
- 預期穩定

--------------------------------------------------

若出現以下條件，必須啟用「Re-rating 模型」：

- 同業估值明顯上修（PE 提升）
- 或市場將公司歸入新成長主題（如 AI / 電源 / 升級）

--------------------------------------------------

👉 在此情境下：

PE 不應使用歷史區間  
而應使用「預期擴張後區間」

--------------------------------------------------

PE 設定方式：

- Bear：原產業 PE
- Base：原 PE + 20~30%
- Bull：原 PE + 50~100%（視題材強度）

--------------------------------------------------

⚠️ 關鍵：

股價上漲的來源 =

（1）EPS 成長  
（2）PE 上修（Re-rating）  

👉 在 early 階段，「PE 上修」影響更大

--------------------------------------------------

⚠️ 強制規則：

若為：

- AA + early + Momentum = Fast

👉 Bull Case 必須包含「PE 擴張」
👉 不可僅使用歷史 PE（否則會嚴重低估）

--------------------------------------------------

⚠️ 補充：

⚠️ 在結構轉變初期，市場常低估未來成長，導致：

- Base Case ≠ 市場合理價
- Bull Case 才可能接近真實目標

👉 因此在 early 階段，評估必須偏向 Bull Scenario

⚠️ 風險限制（避免過度樂觀）：

若：

- 產業 = late
- 或 Momentum ≠ Fast
- 或 籌碼為 Trading Hot（短線資金）

👉 不可套用 PE 大幅擴張
👉 Bull Case 不可過度外推

⚠️ A → B 轉弱判斷（關鍵風控）
=============

當股票原本為 A（強 Alpha）時，必須持續檢查以下條件：

--------------------------------------------------

若出現任一情況，需降級為 B：

1️⃣ Momentum 減弱

- 營收不再加速（YoY / MoM 停滯）
- 法說未再上修
- 產業討論度下降

→ Fast → Moderate / None

--------------------------------------------------

2️⃣ 籌碼轉弱

- 法人由連續買超轉為賣超
- 成交量放大但股價無法創高（出貨跡象）
- 高檔長上影頻繁出現

--------------------------------------------------

3️⃣ 價格行為異常

- 無法再創高（突破失敗）
- 跌破短期趨勢（如 10 日結構）
- 由「緩升」轉為「急拉急跌」

--------------------------------------------------

--------------------------------------------------

⚠️ 強制規則：

若同時出現：

- Momentum 下降
- 籌碼轉弱

👉 必須由 A → B（不可維持 A）

--------------------------------------------------

⚠️ 補充：

若：

- Gap 已由 High → Medium / Low
- 且 Momentum 不再為 Fast

👉 視為「預期已開始被市場消化」

→ 優先降級為 B
