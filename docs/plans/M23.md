你是一位資深量化交易系統架構師 + 台股資金流分析顧問。

我要設計一個「台股每日異常訊號自動化分析系統」。

系統目標不是預測報酬，也不是直接給買賣建議，而是根據昨日台股表現與近三日資金流，產出「今日值得關注的股票清單」。

==================================================
系統核心目標
==================================================

每天 07:00 台北時間自動執行，產出：

1. 昨日台股市場狀態判斷
2. 近三日熱錢流入產業
3. 近三日熱錢流入個股
4. 主線熱錢股 Leader
5. 同步跟漲股 Follower
6. 尚未完全反映的補漲股 Laggard
7. 每檔股票 500–1000 字中文分析
8. 不預測報酬
9. 不給目標價
10. 不輸出買賣建議，只輸出 WATCH / REMOVE

==================================================
系統設計原則
==================================================

1. DB / 程式負責 deterministic filter
2. LLM 負責外部資訊補齊與中文解釋
3. 不只找熱錢已經買的股票，也要找熱錢主線正在擴散到哪裡
4. Output 必須同時包含：
   - LEADER：主線已確認個股
   - FOLLOWER：同族群同步跟漲個股
   - LAGGARD：尚未完全反映但可能補漲個股
5. 排除 ETF、金融股
6. 題材必須至少可能延續 1–2 季，避免短線消息股
7. 必須檢查公司實際業務，不可只看名稱或概念
8. 必須檢查該股位於熱門產業鏈哪一段
9. 必須檢查龍頭股與集團股是否同步上漲
10. 必須納入籌碼、融資融券、價量與技術型態

五、Leader / Follower / Laggard 定義

請設計 deterministic rule：

LEADER：
- 同產業中漲幅領先
- 資金流排名靠前
- 法人連續買
- 成交量放大
- 題材明確

FOLLOWER：
- 與 leader 同產業或同供應鏈
- 已同步上漲
- 漲幅不如 leader
- 籌碼仍支持

LAGGARD：
- 同產業 leader 已漲
- 該股漲幅落後
- 公司業務與題材高度相關
- 近期成交量或法人買盤開始轉強
- 技術面剛轉強或接近突破
- 不只是名字相關，必須業務真的受惠

六、市場狀態 Gating

請設計：

market_state:

- STRONG_BULL
- STRUCTURAL_BULL
- RANGE
- WEAK

並說明不同 market_state 下策略偏好：

- STRONG_BULL：Leader / Follower / Laggard 都可觀察
- STRUCTURAL_BULL：優先主線 Leader 與高相關 Laggard
- RANGE：優先 Laggard，避免追高 Leader
- WEAK：只保留籌碼極強 + 題材明確者
