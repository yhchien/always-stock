# 回測策略文字範例

這份文件說明如何正確撰寫 L3 回測的策略文字，並列出常見的錯誤寫法。

## 策略文字格式規則

```
<進場條件（多個條件用「且」連接）>就買進；<出場條件（多個條件用「且」或「或」連接）>就賣出
```

- 進場條件之間**只支援「且」（AND）**，不支援「或」
- 出場條件之間支援「且」（AND）與「或」（OR）
- 停損/停利條件只能放在出場段
- 句末的「。」可加可不加
- 全形符號（，、。）會自動轉為半形處理

---

## 支援的條件清單

### 價格類

| 條件 | 範例文字 |
|------|---------|
| 收盤價站上 N 日均線 | `收盤價站上20日均線` |
| 收盤價跌破 N 日均線 | `收盤價跌破20日均線` |
| 短均線黃金交叉長均線 | `5日均線黃金交叉20日均線` |
| 短均線死亡交叉長均線 | `5日均線死亡交叉20日均線` |
| 收盤價突破 N 日高點 | `突破20日高點`、`收盤價突破60日高點` |
| 收盤價跌破 N 日低點 | `跌破20日低點`、`收盤價失守60日低點` |

### 成交量類

| 條件 | 範例文字 |
|------|---------|
| 成交量高於 N 日均量 | `成交量高於20日均量` |
| 成交量暴增至 N 日均量的 X 倍以上 | `成交量暴增至20日均量的1.5倍以上`、`成交量大於20日均量2倍` |

### 三大法人類

| 條件 | 範例文字 |
|------|---------|
| 外資買超 | `外資買超` |
| 外資賣超 | `外資轉賣`、`外資賣超` |
| 投信買超 | `投信買超` |
| 投信賣超 | `投信轉賣`、`投信賣超` |
| 自營商買超 | `自營商買超` |
| 自營商賣超 | `自營商轉賣`、`自營商賣超` |
| 外資連買 N 天 | `外資連買3天` |
| 外資連賣 N 天 | `外資連賣3天` |
| 投信連買 N 天 | `投信連買3天` |
| 投信連賣 N 天 | `投信連賣2天` |
| 自營商連買 N 天 | `自營商連買2天` |
| 自營商連賣 N 天 | `自營商連賣2天` |
| 三大法人合計買超 | `三大法人買超`、`三大法人合計買超` |
| 三大法人合計轉賣 | `三大法人轉賣`、`三大法人合計轉賣`、`三大法人賣超` |

### 風險管理類（只能放在出場段）

| 條件 | 範例文字 |
|------|---------|
| 固定停損 % | `停損8%`、`固定停損 10%` |
| 固定停利 % | `停利20%`、`固定停利 15%` |

## 正確使用範例

### 1. 最基本的均線策略

```
收盤價站上20日均線就買進；收盤價跌破20日均線就賣出
```

- 進場：收盤站上 MA20
- 出場：收盤跌破 MA20

---

### 2. 均線 + 外資連買（多條件 AND）

```
收盤價站上20日均線且外資連買3天就買進；收盤價跌破20日均線或外資轉賣就賣出
```

- 進場：站上 MA20 **且** 外資連買 3 天（兩個條件都要滿足）
- 出場：跌破 MA20 **或** 外資轉賣（任一條件即出）

---

### 3. 加入固定停損

```
突破20日高點就買進；跌破10日低點或停損8%就賣出
```

- 進場：突破 20 日高點
- 出場：跌破 10 日低點，或當天虧損達 8% 自動停損

---

### 4. 均線黃金交叉 + 停損停利

```
5日均線黃金交叉20日均線就買進；5日均線死亡交叉20日均線或停損8%或停利20%就賣出
```

- 進場：5 日均線向上穿越 20 日均線
- 出場：死亡交叉、或虧 8%、或賺 20%（任一觸發）

---

### 5. 量價突破型

```
突破60日高點且成交量暴增至20日均量的1.5倍以上就買進；收盤價跌破20日均線就賣出
```

- 進場：突破 60 日高點，且成交量爆量（為 20 日均量的 1.5 倍以上）
- 出場：跌破 MA20

---

### 6. 三大法人合計策略

```
收盤價站上20日均線且外資買超且投信買超就買進；收盤價跌破20日均線或三大法人合計轉賣就賣出
```

- 進場：站上 MA20，外資和投信同步買超（三個條件都要滿足）
- 出場：跌破 MA20，或三大法人合計轉賣

---

### 7. 出場條件使用「且」（更嚴格的出場）

```
收盤價站上20日均線就買進；收盤價跌破20日均線且外資連賣3天就賣出
```

- 進場：站上 MA20
- 出場：**同時** 跌破 MA20 **且** 外資連賣 3 天（兩個條件都觸發才出）

---

## 錯誤使用範例

### ❌ 進場條件用「或」

```
收盤價站上20日均線或外資買超就買進；收盤價跌破20日均線就賣出
```

**問題**：進場條件目前只支援「且」（AND），不支援「或」（OR）。
**修正**：拆成兩組策略分別回測，或改用「且」。

---

### ❌ 停損放在進場段

```
停損8%且收盤價站上20日均線就買進；收盤價跌破20日均線就賣出
```

**問題**：停損/停利屬於風控條件，只能放在出場段（`;` 後面）。
**修正**：

```
收盤價站上20日均線就買進；收盤價跌破20日均線或停損8%就賣出
```

---

### ❌ 缺少進出場分隔符

```
收盤價站上20日均線就買進收盤價跌破20日均線就賣出
```

**問題**：進場條件與出場條件必須用「；」（分號）分隔。
**修正**：

```
收盤價站上20日均線就買進；收盤價跌破20日均線就賣出
```

---

### ❌ 均線交叉參數順序錯誤

```
20日均線黃金交叉5日均線就買進；5日均線死亡交叉20日均線就賣出
```

**問題**：黃金交叉的意義是「短均線由下往上穿越長均線」，所以格式應為「**短均線** 黃金交叉 **長均線**」（短日數在前）。
寫成 `20日均線黃金交叉5日均線` 在數學上永遠不會觸發（20 日均線不會上穿 5 日均線形成黃金交叉）。
**修正**：

```
5日均線黃金交叉20日均線就買進；5日均線死亡交叉20日均線就賣出
```

---

### ❌ 倍數量能條件格式不對

```
成交量大於均量的1.5倍就買進；收盤價跌破20日均線就賣出
```

**問題**：必須指定「幾日均量」。
**修正**：

```
成交量暴增至20日均量的1.5倍以上就買進；收盤價跌破20日均線就賣出
```

---

### ❌ 使用不支援的基本面條件

```
EPS年增率大於20%就買進；跌破季線就賣出
```

**問題**：目前不支援 EPS、營收、本益比等基本面條件。
系統會把這個條件列為 `unsupported_conditions`，並拒絕執行回測。
**處理方式**：移除不支援的條件，或等待後續版本更新。

## 策略文字對應的 DSL 結構

送出策略文字後，系統會在判讀預覽區顯示解析結果：

```
買進：收盤價站上20日均線且外資連買3天；賣出：外資賣超或收盤價跌破20日均線
```

這就是系統「標準化」後的策略文字（`normalized_text`），確保解析正確後才會送去跑回測。

若出現 **「AI 補充解析的條件」** 提示（天藍色），代表你輸入的某個條件寫法不在規則式解析的範圍內，
系統嘗試透過 OpenAI 幫你對應到最接近的受控 indicator。請確認解析結果是否符合你的意圖。

## 系統限制說明

| 限制項目 | 說明 |
|----------|------|
| 資料範圍 | 日線，單一台股/ETF |
| 方向 | 僅 Long（做多），不支援做空 |
| 成交時機 | 訊號日收盤判斷，次一交易日**開盤**成交 |
| 持倉限制 | 同時間只能有一個部位 |
| 交易成本 | 目前固定為 0（不含手續費/交易稅） |
| 進場邏輯 | 多個條件之間固定為 AND |
| 出場邏輯 | 多個條件支援 AND / OR |
