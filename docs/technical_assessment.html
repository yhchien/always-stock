技術面條件與判斷方式

這頁是目前後端 technical_assessment 的使用說明。原始均線、SNR、KDJ、MACD、RSI、量價與相對強度先各自判斷，再收斂成五個獨立 evidence family（證據家族）；LLM 與交易策略讀同一份結論。

先看結論：技術面不是把所有指標票數相加

唯一標準答案：LLM 優先讀 technical_assessment.state、actionability、strength_score、weakness_score、confidence 與各 family 的 signals。舊欄位 technical_status 只保留相容與追溯用途。
Point-in-time raw features只使用目標日以前的價格、成交量、均線、相對強度與動能欄位
↓
Price structure / SNR價格結構、支撐、壓力、突破、跌破
Trend MAMA5/MA10/MA20/MA60、位置、斜率、排列
Relative strength市場 RS、產業 RS、排名改善
Volume-price上漲量／下跌量、當日量、分配
MomentumKDJ、MACD、RSI 的方向訊號
↓
Family-level weighted scores同一個底層價格變化不因 MA5、MA20、MACD 同時出現而重複灌票
↓
stateSTRONG / IMPROVING / NEUTRAL / WEAKENING / BROKEN / CONFLICTED
actionabilityPOSITIVE / WATCH_FOR_ENTRY / NEUTRAL / CAUTION / EXIT_CANDIDATE

一、五個技術證據家族與權重

方向性權重合計 90 分；ATR 不投多空票，只做風險提示，所以高波動不會單獨把股票判成弱勢。

英文 label中文意思權重目前判斷
price_structure價格結構30BREAKOUT_CONFIRMED（確認突破）最強；SUPPORT_BREAKDOWN（支撐跌破）直接標示結構風險。
trend_ma均線趨勢20收盤站上 MA20 且 MA20 上斜為強；同時低於 MA20 與 MA60 為結構破壞。
relative_strength相對強度15市場百分位、產業百分位、5 日排名改善一起判斷。
volume_price量價關係15上漲量主導支持突破；DISTRIBUTION（高檔分配）或下跌量主導轉弱。
momentum動能指標10KDJ、MACD、RSI 先各判方向，再在同一 momentum family 內去重。
risk波動風險不投票ATR 只輸出 LOW／MEDIUM／HIGH 風險，提醒追價與停損距離。
strength_score = Σ(可用 family 權重 × family strength) ÷ Σ(可用 family 權重) × 100

資料缺少時，分母只用可用 family；但 coverage（覆蓋率）低於 40% 會回傳 INSUFFICIENT_DATA，不會因單一指標看起來漂亮就給強勢結論。

二、各指標怎麼判斷

價格結構與 SNR

英文 label / field中文意思判斷方式
SNR / Support and Resistance支撐與壓力目前後端以 20 日支撐／壓力距離與 hold／retest 欄位落地。
breakout_20d_confirmed20 日突破已確認為 true 且壓力回測沒有失敗 → BREAKOUT_CONFIRMED。
support_20d_hold20 日支撐守住為 true → SUPPORT_HOLD，價格結構改善中。
resistance_retest_hold壓力回測守住突破後仍守住 → 保留強勢；為 false → RESISTANCE_RETEST_FAILED。
breakdown_20d_confirmed20 日結構跌破確認為 true → SUPPORT_BREAKDOWN，price_structure state = BROKEN。

所有均線一起看，但歸在同一個 MA family

英文 label中文意思目前用途
SMA / Simple Moving Average簡單移動平均線例如 SMA60（60 日均線）與 sma20_slope_5d_pct。
EMA / Exponential Moving Average指數移動平均線作為可讀的技術指標 label；若資料提供 EMA，仍與均線趨勢同家族，不另加一票。
MA5 / MA10 / MA20 / MA605／10／20／60 日均線看收盤位置、短中期斜率與多空排列。
ABOVE_MA20站上 20 日均線偏改善；若同時 MA20_SLOPE_UP 才升為較強。
BELOW_MA20跌破 20 日均線若 MA20 同時下斜，判定均線轉弱。
BELOW_MA20_AND_MA60同時低於 20 日與 60 日均線trend_ma state = BROKEN。
MA20_SLOPE_UP / MA20_SLOPE_DOWN20 日線上斜／下斜不是只看站上或跌破，也看中期趨勢方向。
BULLISH_MA_ALIGNMENT均線多頭排列作為均線家族內的加強訊號，不會脫離均線 family 重複計分。

動能：KDJ、MACD、RSI 的平等處理

指標 label中文意思正向 signal負向 signal
KDJ隨機指標，觀察短線超買超賣與交叉KDJ_SIGNAL_POSITIVE：golden_cross 黃金交叉、oversold_rebound 超賣反彈KDJ_SIGNAL_NEGATIVE：death_cross 死亡交叉、overbought_turn_down 超買轉下
MACD指數平滑異同移動平均線bullish_cross 多頭交叉、histogram_rising 柱體上升bearish_cross 空頭交叉、histogram_falling 柱體下降
RSI / Relative Strength Index相對強弱指標cross_above_50 上穿 50、oversold_recovery 超賣回復cross_below_50 下穿 50、overbought_turn_down 超買轉下

三者都屬於 momentum family：至少兩個正向且沒有負向才是強；至少兩個負向且沒有正向才是轉弱；一正一負則是 CONFLICTED，不是硬判多或空。

相對強度、量價與風險 label

英文 label中文意思判斷方式
RS_MARKET_STRONG相對大盤強市場 20 日百分位至少 80 且整體沒有明顯負向。
RS_IMPROVING / RS_DETERIORATING相對強度改善／惡化看市場、產業百分位與排名改善三項的合成方向。
UP_VOLUME_DOMINANT上漲量主導20 日上／下跌量比至少 1.2 且當日量不低於 20 日均量。
DOWN_VOLUME_DOMINANT下跌量主導上／下跌量比低於 0.8。
DISTRIBUTION高檔分配／出貨來自量價 soft hint，視為量價轉弱。
ATR / Average True Range平均真實波幅HIGH_ATR 只標高風險；不直接增加 weakness_score。

三、state、分數與行動的對照

英文 label中文意思規則／給下游的語意
STRONG強勢strength_score ≥ 65 且 weakness_score < 45；actionability = POSITIVE。
IMPROVING改善中／轉強中strength ≥ 55 且比 weakness 高超過 10；actionability = WATCH_FOR_ENTRY。
NEUTRAL中性沒有足夠一致方向；不能寫成強勢突破。
WEAKENING轉弱weakness ≥ 55 且 strength < 60；actionability = CAUTION。
BROKEN結構破壞weakness ≥ 70 且價格結構或均線 family 為 BROKEN；actionability = EXIT_CANDIDATE。
CONFLICTED訊號分歧多空分數都高，或 family 互相矛盾；actionability = CAUTION。
INSUFFICIENT_DATA資料不足coverage < 40%；actionability = INSUFFICIENT_DATA。
confidence信心度HIGH：coverage ≥75%、至少 4 個 family 有資料且至少 3 個非中性；MEDIUM：coverage ≥50% 且至少 3 個可用；否則 LOW。
coverage_pct資料覆蓋率五個方向性 family 中，實際有資料的權重比例。
conflicts衝突清單例如 STRENGTH_AND_WEAKNESS_BOTH_PRESENT（強弱同時存在）、BREAKOUT_WITH_WEAK_VOLUME（突破但量價偏弱）。

四、technical_assessment 輸出欄位字典

下面是 LLM、global selector 與交易層實際會看到的 canonical JSON 欄位；欄位名稱保留英文以便程式串接，中文意思固定如下。

英文 label中文意思內容
version版本目前為 technical_v1（技術面第一版規則）。
state整體技術狀態五個 family 的方向收斂後的總結。
actionability可執行性建議把 state 翻成下游可讀的正向、觀察、警戒或出場候選。
strength_score技術強勢分數0～100，依可用 family 權重正向 strength 計算。
weakness_score技術弱化分數0～100，依可用 family 權重負向 weakness 計算。
confidence技術結論信心度HIGH（高）、MEDIUM（中）、LOW（低）。
coverage_pct資料覆蓋率有資料的方向性 family 權重比例。
families證據家族集合包含五個方向性 family：price_structure、trend_ma、relative_strength、volume_price、momentum。
risk風險資訊包含 ATR 波動與風險等級，不加入多空分數。
conflicts衝突訊號清單記錄強弱同時存在或突破與量價背離。
thresholds判斷門檻包含 strong_score（強勢門檻 65）、weakening_score（轉弱門檻 55）、broken_score（破壞門檻 70）與 minimum_exit_confirmation_days（最少出場確認日數 2）。
available資料是否可用family 或 risk 是否有足夠輸入欄位。
detail細節數值例如支撐距離、MA20 距離、RS 百分位、ATR 百分比。
risk_level波動風險等級LOW（低）、MEDIUM（中）、HIGH（高）、UNKNOWN（未知）。

五、例子：LLM 應該怎麼讀

例 1：強勢突破

price_structure=STRONG、trend_ma=STRONG、relative_strength=STRONG、volume_price=STRONG，動能也偏正向，結果可能是：

STRONGPOSITIVE strength 約 80～90、confidence = HIGH。

LLM 可以說「價格結構、均線、相對強度與量價同步偏多」，不能只說「KDJ 黃金交叉所以買進」。

例 2：只有 KDJ 死叉

若價格仍站上 MA20、突破未失敗、RS 與量價正常，但只有 KDJ 出現 death_cross：

NEUTRAL或 IMPROVING，視其他 family 分數而定。

KDJ 只讓 momentum family 變弱，不能把整檔股票直接寫成「全面轉弱」。

例 3：結構跌破

SUPPORT_BREAKDOWN 且收盤同時低於 MA20 與 MA60，weakness 高於 70：

BROKENEXIT_CANDIDATE

即使 RSI 短線超賣，也只能說「可能超賣」，不能抵銷結構破壞。

例 4：突破但量價背離

價格結構為 STRONG，但 DISTRIBUTION 使 volume_price = WEAKENING：

CONFLICTEDCAUTION

這是「突破成立、但需要確認量價是否支持」，不是直接否定突破。

六、下游在哪裡使用

下游使用方式不允許的行為
LLM Research / Reason讀 canonical assessment，將 state、分數、信心度與 family signals 轉成繁體中文。自行重算 MA、SNR、KDJ、MACD、RSI，或把 legacy technical_status 當另一套答案。
Global Selector將技術 assessment 放進每檔 compact selection card；推薦理由若與 assessment 矛盾，後端會做一致性修正。因單一技術 label 就改寫整體候選池。
Shadow PortfolioWEAKENING／BROKEN 可成為獲利保護的弱化證據；BROKEN 是強化弱化訊號。只因單一 KDJ 或 RSI 轉弱就直接賣出。
魚尾 Phase 2與價格結構、相對強度、量價、角色及風險一起決定候選是否進 LLM。把技術分數當成唯一進場條件。
