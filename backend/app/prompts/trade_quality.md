⚠️ 市場狀態判斷（第一優先）
=============

在任何分析前，必須先判斷該股票「當下市場狀態」。

依據買進日前 10 日資料，從以下三點綜合判斷：

1. 三大法人淨買賣趨勢（是否連續買超 / 賣超）
2. 成交量是否明顯放大（相對前期）
3. 股價是否呈現強勢（創高 / 抗跌 / 跌破關鍵位）

將市場狀態分為：

- Hot（資金推動 / 市場關注 / trend）
- Cold（無資金 / 市場忽略 / 無趨勢）

⚠️ 四象限分類（核心框架）
=============

AA（Hot + 成長股）：

AB（Hot + 循環股）：

BA（Cold + 成長股）：
→ 基本面存在但未被市場定價 / 等待資金

BB（Cold + 循環股）：

⚠️ 後續所有估值與交易判斷必須依此調整

⚠️ 分析核心（加權模型）
=============

必須從四個面向整合判斷：

1️⃣ 基本面（財報 / 營收）

* 最新營收（MoM / YoY）
* 獲利趨勢（轉強 / 高檔）
* 是否存在「尚未反映的變化」

2️⃣ 產業與未來預期（最重要）

* 產業循環位置（early / mid / late）
* 未來 1–3 年成長空間（產能 / 需求 / 結構）
* 市場是否正在「上修預期」

👉 股價 = 現在 + 對未來的定價

3️⃣ 籌碼 / 資金

* 法人動向
* 價量結構（吸籌 / 洗盤 / 出貨）
* 是否出現 re-rating 資金

4️⃣ 新聞 / 事件（10 日內）

* 是否改變預期
* 短期 or 中期影響

==================================================
⚠️ 預期差量化模型（Expectation Gap）
=============

必須量化市場「已反映」與「尚未反映」的差距：

步驟：

1️⃣ 推導「合理未來 EPS」（未來四季）

2️⃣ 根據歷史區間，定義：
- 保守 PE
- 中性 PE
- 樂觀 PE

3️⃣ 計算三種情境價格：

- Bear Case = EPS × 低 PE
- Base Case = EPS × 中 PE
- Bull Case = EPS × 高 PE

4️⃣ 判斷目前股價位置：

- 若接近 Bear → 低預期（downside 小）
- 若接近 Base → 預期合理
- 若接近 Bull → 高預期（容易失望）

5️⃣ 定義「預期差」：

Expectation Gap = Bull Case - Current Price

並判斷：

- Gap 大 + 邏輯成立 → 正期望報酬
- Gap 小 → 已反映
- Gap 負 → 過度樂觀（風險）

==================================================
⚠️ 估值調整（依四象限）
=============

AA：
→ PE 可上修至歷史區間 +10~20%（資金溢價）

AB：
→ 僅用中低 PE（避免高點）

BA：
→ 用中性或偏低 PE（等待 re-rating）

BB：
→ 用低 PE 或不給目標價（偏空）

==================================================
⚠️ 分類結果（最終）
=============

A（高品質交易）：
→ AA 且 Expectation Gap 明顯

B（中性）：
→ AB 或 BA 或 Gap 已反映

C（弱勢）：
→ BB 或 Gap 為負
